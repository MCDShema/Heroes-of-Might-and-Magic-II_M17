## ✨ Переваги та налаштування цієї версії

- 💿 **Повний оригінальний CD-образ гри (`homm2.iso`)**:
  - Скрипт `dos.bat` автоматично монтує віртуальний CD-привід (`imgmount d homm2.iso -t iso`).
  - Працює оригінальний оперний/оркестровий CD-Audio саундтрек та всі відеовставки.
- 🕹️ **Відкаліброване керування стіком та кнопками M17**:
  - Файл `mapper.map` налаштований спеціально під контролер M17:
    - **Лівий аналоговий стік**: Плавний рух курсору миші по карті та в замку.
    - **Кнопка A**: Лівий клік миші (вибір героя, переміщення, напад, підтвердження).
    - **Кнопка B**: Правий клік миші (інформація про клітинку карти, ворогів, артефакти).
- 🔊 **Чистий звук Sound Blaster 16**:
  - Конфігураційні файли `DIG.INI`, `MDI.INI` та `HEROES2.CFG` відкалібровані для чистого звучання без спотворень та тріску.
- ⚡ **Автоматичне збирання образу**:
  - При першому запуску скрипт `launch_pc.sh` самостійно збирає образ `homm2.iso` з частин за лічені секунди.

## 📦 Інструкція зі встановлення

1. **Завантажте архів гри**:
   - Натисніть кнопку **Code ➔ Download ZIP** у верхній частині сторінки або скористайтеся [цим прямим посиланням](https://github.com/MCDShema/Heroes-of-Might-and-Magic-II_M17/archive/refs/heads/main.zip).
2. **Розпакуйте архів**:
   - Розархівуйте ZIP-файл на вашому комп'ютері.
3. **Скопіюйте на картку пам'яті M17**:
   - Вставте microSD картку консолі в комп'ютер.
   - Скопіюйте папку `roms` із розпакованого архіву прямо в корінь вашої картки пам'яті (файли автоматично опиняться у `roms/pc/`).
4. **Запустіть гру на консолі**:
   - Вставте картку назад у консоль M17 та увімкніть її.
   - У головному меню відкрийте розділ **DOS x86** (або PC).
   - Знайдіть пункт **dos** (або *Heroes of Might and Magic II*) та натисніть кнопку **A** для старту!

## 📁 Структура файлів на картці пам'яті

```text
/roms/pc/
├── launch_pc.sh                      # Скрипт запуску DOSBox SVN
├── gamelist.xml                      # Опис та метадані для EmulationStation
├── images/
│   └── Heroes of Might and Magic II.png  # Обкладинка гри
└── Heroes of Might and Magic II/     # Папка з файлами гри
    ├── dos.bat                       # Стартовий файл запуску (пункт 'dos' в консолі)
    ├── homm2.iso.part*               # Повний CD-образ гри (авто-збирання)
    ├── HEROES2.EXE                   # Виконуваний файл гри
    ├── mapper.map                    # Маппінг стіка та кнопок M17
    ├── HEROES2.CFG                   # Налаштування гри
    ├── DIG.INI / MDI.INI             # Аудіодрайвери Sound Blaster 16
    ├── DATA/                         # Графічні архіви
    ├── MAPS/                         # Усі сценарії та карти
    ├── MUSIC/ & SOUND/               # Музика та звукові ефекти
    └── GAMES/                        # Збереження ігор
```
